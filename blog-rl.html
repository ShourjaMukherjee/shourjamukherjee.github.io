Reinforcement learning, from scratch

November 13, 2026 · 3 min read

Reinforcement learning (RL) is learning by trial and score.

Nobody shows the correct answer. You try something. You get a score. You do more of what scored well.

A child learns to ride a bicycle this way. No manual. Only falls and fewer falls.

The loop

WordMeaningBicycle example
AgentThe learnerThe child
EnvironmentThe world around the agentBicycle and road
StateWhat the agent sees nowSpeed, tilt
ActionWhat the agent doesSteer, pedal
RewardThe score for the action+1 upright, −1 fall
PolicyThe rule: state → action"Tilt left, steer left"

The goal: find the policy that gets the most total reward.

The smallest example

A machine has two buttons. Each button gives a coin some of the time. Button A pays 30% of the time. Button B pays 70%. The agent does not know these numbers.

The agent keeps one number for each button: the average reward so far. Then it repeats two steps:

  1. Push the button with the higher average.
  2. Move that average a small step toward the result.
import random

pay = [0.3, 0.7]      # hidden from the agent
Q = [0.0, 0.0]        # the agent's estimate for each button
N = [0, 0]            # pushes for each button

for step in range(1000):
    if random.random() < 0.1:
        a = random.randrange(2)      # explore
    else:
        a = Q.index(max(Q))          # exploit
    r = 1 if random.random() < pay[a] else 0
    N[a] += 1
    Q[a] += (r - Q[a]) / N[a]        # move toward the result

print(Q, N)   # about [0.26, 0.71], [139, 861]

After 1,000 pushes, the estimates are near the true values. The agent pushes button B most of the time. It learned from rewards only.

Explore or exploit

Look at the line with 0.1. One time in ten, the agent pushes a random button.

Remove that line and the agent can fail. If button A pays first, the agent pushes A forever. It never finds out that B is better.

  • Exploit: do what looks best now.
  • Explore: try something else, to learn.

Every RL method must balance these two.

Late rewards

The buttons pay immediately. Most real tasks do not.

In chess, the only reward comes at the end: win or lose. Which of the 40 moves caused the win? This is the credit assignment problem. It is the hard part of RL.

The usual answer has two parts:

  • Return. Score an action by all the reward that follows it, not only the next reward.
  • Discount. Count later rewards a little less. A reward 10 steps away is worth less than a reward now.

In one line: act, get a reward, adjust, repeat. The reward defines what the agent learns, so choose the reward with care.
