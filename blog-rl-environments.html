RL environments, from scratch

November 13, 2026 · 3 min read

An environment is the world that the agent practises in.

A pilot learns in a flight simulator. The simulator is the environment. A crash there costs nothing.

Two functions

An environment needs only two functions.

FunctionWhat it doesWhat it returns
reset()Starts a new tryThe first state
step(action)Applies one actionNew state, reward, done

One try, from reset to done, is an episode.

The smallest environment

A corridor has 5 cells. The agent starts in cell 0. The goal is cell 4.

class Corridor:
    def reset(self):
        self.pos = 0
        return self.pos

    def step(self, action):              # -1 = left, +1 = right
        self.pos = max(0, self.pos + action)
        done = self.pos == 4
        reward = 1 if done else 0
        return self.pos, reward, done

That is a full environment. Now put an agent in it. This agent moves at random.

import random

env = Corridor()
state = env.reset()
done = False
steps = 0

while not done:
    action = random.choice([-1, 1])
    state, reward, done = env.step(action)
    steps += 1

print(steps)   # about 20 on average

The shortest path is 4 steps. The random agent needs about 20. Learning closes that gap.

Four decisions

To design an environment, you make four decisions.

DecisionQuestionCorridor
StateWhat does the agent see?The cell number
ActionsWhat can the agent do?Left, right
RewardWhat is good?+1 at the goal
EndWhen does a try stop?At the goal

The reward is the hardest decision. The agent learns what the reward pays for, not what you meant.

Environments for language models

The same four decisions apply when the agent is a language model.

PartExample: fix a bug
StateThe task text and the files
ActionsRead a file, edit a file, run a command
Reward1 if the tests pass, 0 if not
EndThe model says "done", or a step limit

A task is one start position in the environment. One environment can hold thousands of tasks.

An environment is a state, a set of actions, a reward, and an end. Two functions hold all four.
